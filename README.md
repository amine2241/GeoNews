# Map-Based News Platform

This project is an interactive web application that allows users to view and share news articles based on geographical locations. It uses a world map to display news from different regions, making it easier to explore global events visually.

## Description

The application integrates an interactive map where users can select locations to see related news articles. News data is retrieved from an external API and displayed dynamically based on the selected area.

## Technologies Used

* HTML, CSS, JavaScript
* Leaflet.js for the interactive world map
* World News API for news data retrieval

## Features

* Interactive world map
* Location-based news display
* Real-time news data from an external API
* Simple and user-friendly interface
